# NFTOps — Interactive CLI for NFT Minting & Contract Deployment

A single-command interactive CLI that helps non-developers mint NFTs and deploy contracts across **EVM chains** (Ethereum, Polygon, Base, Arbitrum) and **Solana**.

No scripts to edit. Just run the CLI, answer prompts, and paste your private key when asked.

---

## Tech Choice: Node.js + TypeScript

**Why this stack:**
- **ethers.js** (EVM) and **@solana/web3.js** + **Metaplex Umi** (Solana) are the canonical libraries for their respective ecosystems, with the largest communities and clearest documentation.
- **TypeScript** provides type safety without requiring a compiler at runtime (builds to plain JS), making it easier to debug and extend for non-devs who want to read the code.
- **Hardhat** compiles Solidity contracts with zero configuration and integrates seamlessly with ethers.js.
- **@inquirer/prompts** gives a clean, guided CLI UX with no extra setup.

Python alternatives (web3.py, anchorpy) have smaller communities for web3 tasks and require more manual ABI/keypair handling. Node/TS is the path of least resistance here.

---

## Features

### EVM (Ethereum, Polygon, Base, Arbitrum)
- **Deploy contracts**: ERC-721 or ERC-1155, using included OpenZeppelin templates.
- **Mint NFTs**: Call `safeMint` (ERC-721) or `mint` (ERC-1155) on already-deployed contracts.
- **Chain presets**: Mainnet + testnet for Ethereum, Polygon, Base, and Arbitrum.
- **Secrets handling**: Paste private key at the prompt (hidden input) OR use a `.env` file.

### Solana
- **Mint simple NFTs**: Uses Metaplex Umi's `createNft` helper — mint, metadata, and token account in one call.
- **Devnet + Mainnet**: Choose at the prompt.

### Output
Every operation writes a JSON file to `output/` with:
- Transaction hash / signature
- Contract address / mint address
- Explorer link
- Timestamp

## Setup

### 1. Install dependencies
```bash
npm install
```

### 2. Compile the Solidity contracts
```bash
npm run compile
```
This runs `hardhat compile` and generates the `artifacts/` folder with compiled ERC-721 and ERC-1155 contracts.

### 3. (Optional) Configure environment variables
Copy `.env.example` to `.env` and fill in private keys if you don't want to paste them at the prompt:
```bash
cp .env.example .env
```
Edit `.env`:
```bash
EVM_PRIVATE_KEY=0x...
SOLANA_PRIVATE_KEY=...
```

**Note:** The CLI will ask you to paste keys at the prompt if you skip this step. Env vars are optional.

## Usage

### Run the CLI (dev mode, no build)
```bash
npm run dev
```

### Or build once, then run
```bash
npm run build
npm start
```

The CLI presents an interactive menu:
1. **Mint an NFT** → Choose EVM or Solana → Follow prompts
2. **Deploy an EVM contract** → Choose chain → Choose ERC-721 or ERC-1155 → Deploy
3. **Exit**

## Contract Templates

### MyERC721.sol (ERC-721)
- **Constructor:** `(string name, string symbol, address initialOwner)`
- **Mint function:** `safeMint(address to, string memory uri) returns (uint256 tokenId)`
- **Metadata model:** Per-token URI (pass a full URI like `ipfs://CID/1.json` for each mint)
- **Ownership:** Only the `initialOwner` can mint.

### MyERC1155.sol (ERC-1155)
- **Constructor:** `(string baseUri, address initialOwner)`
  - `baseUri` should contain `{id}`, e.g., `ipfs://CID/{id}.json`
- **Mint function:** `mint(address to, uint256 id, uint256 amount)`
- **Metadata model:** Base URI + token ID (clients substitute the hex token id)
- **Ownership:** Only the `initialOwner` can mint.

Both templates use OpenZeppelin 5.0 and are compiled to artifacts by Hardhat.

## Security & Best Practices

1. **Never commit `.env`** — it's in `.gitignore` by default.
2. **Test on testnets first** — Sepolia (Ethereum), Amoy (Polygon), Base Sepolia, Arbitrum Sepolia, or Solana Devnet all give free test tokens.
3. **Use a burner wallet for testing** — Don't paste mainnet keys with real funds into any CLI until you've verified the code.
4. **Public RPCs are rate-limited** — For production, use a dedicated RPC provider (Infura, Alchemy, Quicknode) and override the RPC at the prompt or in `.env`.

## Troubleshooting

### `Contract artifact not found`
Run `npm run compile` to generate the `artifacts/` folder.

### `EVM_PRIVATE_KEY is not set`
Either paste your key at the prompt (choose "Paste it now"), or add it to `.env`:
```bash
EVM_PRIVATE_KEY=0x1234...
```

### `insufficient funds for intrinsic transaction cost`
Your wallet doesn't have enough native tokens (ETH, POL, SOL) to cover gas. Get testnet tokens from a faucet:
- Ethereum Sepolia: https://sepoliafaucet.com
- Polygon Amoy: https://faucet.polygon.technology
- Base Sepolia: https://www.coinbase.com/faucets/base-ethereum-goerli-faucet
- Arbitrum Sepolia: https://faucet.arbitrum.io
- Solana Devnet: `solana airdrop 2` (requires Solana CLI) or https://solfaucet.com

### TypeScript errors
Run `npm run typecheck` to verify. If you see missing types, make sure you ran `npm install`.
